Signed release build, ~50 MB — satellite tiles at 3.4 m/px. Install from this
page on any Android 8+ device.

**Check it offline before you rely on it:** airplane mode on, force-stop, reopen.
The map must render identically with no network. Then tap **Self-test** and share
the report — it prints what actually drew, what routed, and where the GPS thinks
you are.

Still unmeasured: battery drain with the screen on, and GPS accuracy under
canopy. Those need a real ride.
