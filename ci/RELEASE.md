**Take 117 — ALL OF MICHIGAN. The one-stop Michigan app, first cut.**

Signed release build. Confirm **Tools → Diagnostics → About this build says
take 117** — then understand what you are holding: the entire state, both
peninsulas and Isle Royale, offline. 473,674 routable edges, 76 rivers with
float times, 8,145 landcover areas, every DNR closure and restriction
statewide, in about 127 MB.

### What changed since 116, beyond the obvious

- **Home is yours now**: unset until you set it (tap a place → "Make this
  home", or press-and-hold → Set home), remembered across launches, and Return
  Home tells you plainly if none is set.
- **The app opens where YOU are**, zoomed a bit out, the moment a fix lands —
  home if you have no fix, mid-Michigan if you have neither.
- **Routing at state scale**: six profiles, each answering in about a tenth of
  a second. Absurd detours are discarded; a profile that finds nothing sane
  says nothing instead of guessing.
- Statewide honesty: contour lines and named summits are absent BY DECLARATION
  at this scale (the app says so); Silver Lake Dunes is an open riding AREA and
  the trail-line rules know it.
